What this project does

This model learns from labeled image folders (for example cats and dogs), then predicts class labels for new images. It is designed as a complete deployable pipeline, not only a notebook experiment.

Data Pipeline

Loads ImageFolder data, applies augmentation, creates train/validation splits.

Model Training

Transfer learning with ResNet50/EfficientNet, early stopping, scheduler, logging.

Deployment Interfaces

CLI inference, Streamlit dashboard, and FastAPI endpoint for app integration.

Architecture flow

  1. Dataset in class folders
  2. Transforms and DataLoader
  3. Transfer learning model training
  4. Best checkpoint saved
  5. Inference via CLI, Dashboard, and API

Run locally

Use these commands from project root:

C:/Python314/python.exe -m pip install -r requirements.txt
C:/Python314/python.exe src/train.py --data_dir sample_data --arch resnet50 --epochs 15
C:/Python314/python.exe -m streamlit run dashboard.py --server.port 8501
C:/Python314/python.exe -m uvicorn src.api:app --host 0.0.0.0 --port 8000

Important note about GitHub Pages

GitHub Pages hosts static files. It cannot run Python model inference directly. For interactive online inference, deploy Streamlit/FastAPI separately and link it here.
